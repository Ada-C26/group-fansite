Coworking Agreement

Accessibility Needs

We will respect each other’s schedules and personal needs. Everyone should have access to GitHub, Slack, and all project materials. If someone needs help or extra time, they should communicate with the team.

Collaboration vs. Individual Work Expectations

Each of the four team members will be responsible for their own page of the website. We will use GitHub to share our code and Slack to communicate. We will help each other when needed and work together on the overall website design. Everyone should complete their tasks on time.

Learning Style

We learn best by practicing, writing our own code, and discussing problems together. We will share useful resources, ask questions, and help each other understand new concepts.

Preferred Feedback Style

We prefer friendly, honest, and respectful feedback. We will give specific suggestions and explain what can be improved. We will listen to each other’s ideas and be open to changes.

One Team Communication Skill to Improve

We want to improve our communication and time management. We will share regular updates about our progress and let the team know early if we have any problems or delays.

Optional: Other Agreements

* Each team member is responsible for completing their assigned tasks.
* We will communicate through Slack and keep everyone updated.
* We will review our changes before pushing to GitHub.
* We will respect each other’s opinions and ideas.
* We will try to finish the project by Friday evening so we don’t have unfinished work over the weekend.
* We will help each other if someone gets stuck.
